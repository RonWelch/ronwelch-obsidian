## What happens when AI agents start paying each other? Watch Mastercard Agent Pay for Machines in action

---

## At Cloudflare Connect, Mastercard is showing how Agent Pay for Machines helps AI agents pay for digital services while keeping people and businesses in control.

---

AI agents are becoming more capable, reliable and able to work with one another. Increasingly, they also need to pay for things. An agent might buy data from one provider, use an AI model from another and pay for computing power from a third. In other words, AI agents are becoming economic actors.

But how does an agent actually pay?

Paid digital services today typically require an account, API key, prepaid credits or billing relationship with each provider. That works when an agent uses one or two services. It becomes harder when the agent needs to choose different services as a task unfolds, paying only for what it uses along the way.

Then there’s trust. Who gave the agent permission to spend? How much can it spend? What can it spend that money on? And who is it paying?

Those questions need to be answered instantly, at machine speed. That's why we built [Agent Pay for Machines](https://www.mastercard.com/us/en/business/artificial-intelligence/mastercard-agent-pay/agent-pay-for-machines.html). It builds on [x402](https://x402.org/), an open protocol that lets digital services request payment online, and connects it with the trust, security and reach of the Mastercard network.

Today at [Cloudflare Connect](https://www.cloudflare.com/connect/), Mastercard is showing how Agent Pay for Machines allows AI agents to securely purchase digital services on behalf of businesses while staying within approved budgets and permissions.

Following end-to-end pilots with [Cloudflare](https://www.cloudflare.com/), [Ant International](https://www.ant-intl.com/), [AIsa](https://aisa.one/), [Base](https://www.base.org/), [BVNK](https://www.bvnk.com/), [Coinbase](https://www.coinbase.com/) and [Hype](https://urldefense.com/v3/__https:/www.hy.pe/__;!!NDdRaFrjhKsg!p0uW8eDMTOUVrQXXx2TZJ45Q731Tef-sRmBDU_1LiT3dxBh6ppGpRlKKefwNqX3KhhBRLEfayq8qjQzcVAiyvcmR-mgx9Mk$), we’re also opening [Agent Pay for Machines Early Access](https://www.mastercard.com/global/en/business/payments/consumer-payments/next-gen-payments/digital-asset-solutions/cloudflare-connect-2026.html), giving developers access to the APIs, tools and documentation needed to begin building and testing agent-to-agent commerce experiences.

Payments aren't the hard part. Authority is. The challenge is making sure the right agent can complete the right transaction with the right permissions.

#### Authorize once. Transact many times. Guarantee payment now. Settle later.

The idea is simple. A business gives an agent a job and a spending limit. When the agent encounters a paid service, the service responds with “402 Payment Required,” the internet's way of saying that payment is needed to continue.

The agent creates a digitally signed payment voucher, which is a secure promise to pay within its approved limit. The provider verifies it, delivers the service and the work continues.

These interactions happen off-chain at machine speed. Providers can combine vouchers and redeem them later. Agents keep working and paying for what they need without unlimited spending authority or a new billing relationship for every service.

#### Giving agents a trusted way to transact

At Cloudflare Connect, we're bringing this to life with Hype, a marketing agency that already uses AI agents in its campaign work.

![poster](https://www.mastercard.com/content/dam/mccom/shared/news-and-trends/press/2026/Agent%20Pay%20for%20Machines%20pilot%20demo.png)

In the pilot demo, Hype gives an AI agent a task and a defined budget: Plan a sample campaign for a protein bar launch. Running on an agent platform such as [Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/), the agent discovers registered Agent Pay for Machines providers and returns with a two-step plan: Conduct social media research from AIsa and create campaign images through Cloudflare AI Gateway.

Hype approves the funding, limiting the agent to the defined task and budget. Then the agent gets to work. When payment is needed, the service responds with “402 Payment Required” through Cloudflare Monetization Gateway. The agent signs a voucher, the seller verifies it and the work continues.

First comes the research from AIsa. Then come eight campaign images from Cloudflare.

Nine payments. Two independent merchants. One approved budget. No separate accounts, API keys or invoices. The agent pays only for what it uses while Hype stays in control.

Behind the scenes, [Coinbase Developer Platform](https://www.coinbase.com/developer-platform) provides the wallet infrastructure used to fund the agent, while Base provides the on-chain settlement network. BVNK then acts as the agent wallet, using [Mastercard Global Money Platform](https://www.mastercard.com/us/en/news-and-trends/press/2026/october/mastercard-and-bvnk-launch-global-money-platform-to-power-a-mult.html) to handle the payment and settlement on both sides, in fiat or stablecoins. Sellers can then get paid in their preferred currency, token or rail.

This same model can support AI models, data, computing power, APIs and other digital services.

#### Start building for an open agent economy

Agent Pay for Machines is designed to work across the ecosystem. Agent platforms run agents, wallets and payment providers supply funds, and merchants offer services. Mastercard connects them through a common layer of trust.

Through [Agent Pay for Machines Early Access](https://ap4m.build/info), we’re making the first version of our buyer- and seller-side APIs available to developers, along with a toolkit, sandbox and developer documentation.

This is just the start. Our roadmap will be shaped by what customers and partners need. We want developers to test Agent Pay for Machines, try different use cases and tell us what would make it more useful.

Whether you’re building agents, platforms, payment infrastructure or services for agents, we want to build with you.

The web gave software a way to communicate. APIs gave software a way to use services. Now AI agents need a way to pay for them. That’s what we’re building. Together, we can make the agentic economy open, interoperable and trusted from the start.
