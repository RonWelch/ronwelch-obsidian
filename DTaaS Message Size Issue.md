Background Information / Problem Statement:

Platforms and Solutions attempted to Release five End Item Bills Of Material (BOMs) for the AMPV program from EPDM (Windchill) to Oracle EBS via a Manufacturing Change Notice (MCN) on May 15, 2026. The resulting DTaaS message was 43.85 MB in size. The message was rejected by DTaaS with an error message indicating that the maximum message size had been exceeded. It was subsequently established that the maximum message size that DTaaS will accept is 21 MB. As a work around, the MCN containing the five top level End Item BOMs was split into five smaller MCNs, with one End Item BOM for each.
